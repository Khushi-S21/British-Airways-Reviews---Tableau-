# ✈️ British Airways Tableau Dashboard

## 📌 Overview

This project is an interactive Tableau dashboard that visualizes key operational and financial data for **British Airways**. The goal is to provide meaningful business insights into flight performance, delays, passenger trends, and route-level analytics.

The project was developed as part of a guided project experience to strengthen my Tableau skills. I enhanced and customized the dashboard by applying my own analytical logic, visual design preferences, and storytelling approach to better reflect real-world business intelligence reporting.

---

## 💡 Key Contributions

- Customized dashboard layout for improved clarity and user experience.
- Added filters for time period, flight class, and routes to increase interactivity.
- Refined visual elements, tooltips, and formatting for professional presentation.
- Incorporated seasonal trends and route-level insights.
- Applied calculated fields and parameter controls in Tableau.

---

## 📊 Features

- Analysis of flight delays and cancellations.
- Passenger traffic trends by route and season.
- Revenue insights segmented by class and route.
- Interactive controls for dynamic data exploration.

---

## 🛠 Tools Used

- **Tableau Desktop**
- Sample Airline Dataset (structured for training and analysis purposes)

---

## 🚀 How to View the Dashboard

1. Download the `.twb` file from this repository.
2. Open it using **Tableau Desktop** (or Tableau Public).
3. Use the interactive filters and visuals to explore insights across different dimensions.
